# Censor BOT

Стартовый проект Censor BOT для MAX.

## Что уже есть

- MAX Bot API через `maxapi`
- Webhook
- SQLite в `/app/data/censor.db`
- `/start`
- `/myid`
- `/admin`
- `/activate КОД`
- кнопочное меню
- админ-панель-заготовка
- учёт пользователей
- учёт чатов
- подписки PRO на 30 дней
- одноразовые промокоды
- приветствие новых участников
- базовая фильтрация запрещённых слов
- удаление ссылок от новых участников
- журнал действий модерации
- заготовка рекламного модуля

## Первый запуск

1. Создайте переменные окружения в Bothost.
2. Задайте `BOT_TOKEN`.
3. Пока оставьте `ADMIN_USER_IDS` пустым.
4. После запуска откройте бота в MAX и отправьте `/myid`.
5. Вставьте полученный ID в `ADMIN_USER_IDS`.
6. Перезапустите бота.
7. Добавьте бота в тестовую группу и выдайте ему права администратора с возможностью удаления сообщений.

## Webhook

Задайте:

`WEBHOOK_URL=https://ВАШ-ДОМЕН/webhook`

MAX требует HTTPS для Webhook. Не публикуйте токен бота в GitHub.

## Важно

Это стартовая версия архитектуры. Перед публичным запуском нужно завершить:
- полноценный мастер создания/выдачи промокодов;
- продление/пауза подписок;
- привязку подписки к чатам;
- настройки модерации каждого чата;
- муты/баны/предупреждения;
- расширенную статистику;
- полноценную рекламную рассылку;
- автоматические фоновые задачи;
- резервное копирование БД.
